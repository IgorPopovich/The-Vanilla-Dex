# The Vanilla Dex

Responsive Pokémon encyclopedia built with **Vanilla JS** + **PokéAPI**.

## Development

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (Vite).

## Features

- Pokémon gallery (Gen 1, first 151)
- Live search + type filter
- Modal with stats, abilities, and evolution chain
- Pagination / infinite scroll (chunks of 20)
- Favorites (localStorage)
- Theme toggle
- Compare tool (two Pokémon side-by-side)
